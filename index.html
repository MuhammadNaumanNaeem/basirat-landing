Model Performance

AI Model Details

Two specialised models work in tandem — one detects and locates objects in milliseconds, the other narrates the full scene in natural language.

Object Detection
YOLO11n

The lightest variant of the YOLO11 family, optimised for CPU inference on mobile-grade hardware. Detects 80 COCO object categories in a single forward pass, delivering bounding boxes, class labels, and confidence scores that feed the Direction & Distance Estimation module.

Bootstrapping Language-Image Pre-training (BLIP) generates free-form, contextually rich captions from camera frames. What It Does

Core Capabilities

Every module is designed for hands-free, eyes-free operation — so the user stays in control using only their voice.

🎙️
Voice Command Control

Fully hands-free interaction via the phone's microphone. Google Speech API converts spoken words into commands that drive every feature.

🧭
Scene Narration

BLIP generates natural-language descriptions of the live camera view — not just a list of objects, but a sentence describing the whole environment.

🔍
Specific Object Search

Say "find my bag" and the app filters YOLO detections in real time, announcing the direction and step-count distance to that exact item.

📏
Direction & Distance

Object positions are converted to left/right/forward cues and step-count estimates so the user can navigate toward or around any detected item.

👤
Face Recognition & Memory

Recognised faces are stored in PostgreSQL. When a known person appears, their name is announced instantly — supporting safe, social independence.

🚨
Emergency Help Module

Saying "Help!" or "Call emergency" triggers instant alerts — phone calls or SMS — to predefined emergency contacts, even without visual interaction.
